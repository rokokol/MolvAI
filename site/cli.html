CLI reference

The molva command

One binary holds the CLI and the daemon. The page lists the options that molva --help prints; the repository is the source of truth when the two disagree

Canonical source: crates/molva/src/main.rs

Global options

Options accepted before or after the subcommand
OptionMeaning
--configPath to the settings file, default ~/.config/molva/config.toml; MOLVA_CONFIG sets the same
--socketPath to the daemon socket, default $XDG_RUNTIME_DIR/molva.sock; MOLVA_SOCKET sets the same
--versionThe version of the binary
--helpHelp for the command and for every subcommand

Exit codes

For scripts and compositor binds, the code matters
CodeMeaning
0Everything worked
2Wrong arguments or an unknown name
3The daemon is not running or does not answer
4The daemon is busy with the previous phrase
5Error of the recognition engine
6Could not read or write a file
7The daemon is already running; the second copy exits with a message

Dictation and the daemon

These commands talk to the running daemon over a local socket. A compositor bind calls them, and a script reads their exit code

molva daemon

Starts the process that owns the microphone, the model and the state. One instance per user

molva daemon
OptionMeaning
--foregroundNotifications go to the log instead of the desktop. The process does not go to the background in any case

molva record

Start, stop, toggle and cancel. The subcommands take --mode dictation|command and --style

molva record <action>
ActionEffect
startOpen the microphone and begin a phrase
stopClose the microphone and process the phrase
toggleStart if idle, stop if recording, which is the hands-free bind
cancelThrow the recording away without creating a phrase
molva record toggle --mode command

The rest of the dictation set

Everyday commands around a dictation
CommandWhat it does
molva statusThe daemon state. --json for machines, --watch to keep printing events
molva devicesThe input devices that audio.device can name
molva test-injectPastes a test string into the active field and prints the method that worked
molva setup <target>Prints the binds for hyprland, sway, kde or gnome. --ptt replaces the key, --write writes the Hyprland Lua file
molva completions <shell>A completion script for bash, zsh, fish, PowerShell or elvish
molva secretset, delete and status for keys. The value is read from stdin and never printed
printf '%s' "$KEY" | molva secret set llm

molva transcribe

Offline transcription of audio and video. It never touches the microphone and never pastes anywhere, so it fits scripts and CI

molva transcribe [OPTIONS] <PATH>… · a path, a directory or - for stdin
OptionMeaning
--timecodesPrint segments with their start and end
--jsonA JSON array instead of text
-o, --outA file or a directory for the result; without it the text goes to stdout
--recursiveWalk nested directories
--stdin-formatA format hint for a stream: wav, mp3, ogg, flac, m4a
--modelA model name from the catalog for this run
--engineThe recognizer; fake runs the pipeline without weights
--languageAn ISO-639-1 code; by default it comes from the settings
--styleRun the text pipeline with this style
--no-llmDo not call the language model in post-processing
--copyCopy the result to the clipboard and leave it there
molva transcribe interview.mp4 --timecodes -o interview.txt

One unreadable file in a batch does not cancel the others. The exit code 6 reports that not everything went through

molva search

Finds text in the transcriptions of audio and video files. It reads the same journal as the history, so there is no second index to drift

molva search [OPTIONS] [QUERY] · an empty query prints the newest transcriptions
OptionMeaning
--limitMaximum hits, default 20; 0 means no limit
--since, --untilA time window: 7d, 24h, 2026-09-01 or an RFC 3339 moment
--jsonA JSON array of hits
molva search "deadline" --since 7d

molva history

The phrase journal, read and edited from the terminal. The filters work on the whole file

molva history [OPTIONS] [SUBCOMMAND]
Option or actionMeaning
--limitHow many of the latest entries, default 20
--searchA substring in the text of the phrase
--appOnly phrases from this application
--since, --untilA time window
--formattable, json, plain or rofi
show <id>One entry in full
paste [id]Paste a phrase again. --last takes the newest one
delete <id>Delete one entry
clearClear the whole history; --yes skips the question
export <file>Write JSONL or CSV, by the file extension

molva models

Weights management against the same catalog the GUI and the Nix module read

molva models <action>
ActionMeaning
listThe catalog and which files are already downloaded; --json for machines
pull <name>Download over HTTPS and check the SHA-256. --force downloads again, --all-small takes every file under 500 MB
verify <name>Check the checksum of an installed file
remove <name>Delete an installed file
path <name>Print the path of the weights file
molva models pull gigaam-v3-e2e-rnnt-q4_k_m

molva config

The settings file, addressed by dotted keys. A wrong value fails with the file path and the key name

molva config <action>
ActionMeaning
pathThe path of the settings file in use
get [key]The value at a dotted path, or every setting
set <key> <value>Write one value
editOpen the file in $EDITOR and check it afterwards
validateCheck the file without changing it
resetRestore the default values; --yes skips the question
export, importA settings profile as a file
reloadAsk the running daemon to reread the file
molva config set stt.language auto

The recognizer and the paste chain are built when the daemon starts, so a changed model, engine or output method needs a daemon restart. molva config reload passes the other settings to the running daemon

molva doctor

Diagnostics for the session, the compositor, the paste tools, the permissions, the daemon socket, the weights and their checksum, and the model provider

molva doctor

Run it before asking for help. It names the failed part and the next step, and it is the first question in every troubleshooting thread

The remaining commands

Statistics, styles, the dictionary and benchmarks
CommandWhat it does
molva statsWords, pace, time and the record over --period today|week|month|all; --series day|session|app, --json; subcommands export and reset
molva styleslist the post-processing styles, show the system prompt of one
molva dictionarylist, add, reload and stats for the term dictionary
molva benchWord and character error rate plus latency on the audio fixtures in the repository
