FAQ

Questions a careful person asks

Short answers, each with the place where the repository says the same thing at length

What exactly is MolvAI?

System-wide voice input: hold a key, speak, release, and the text appears in the active field of any application. Recognition, the dictionary, the rules and the paste run on your computer. It is MIT licensed and written in Rust

Do I need a video card?

No. The default model, GigaAM-v3 Q4_K_M, is built for the CPU and weighs 175 MiB. Linux and Windows builds can use Vulkan when a device exists, and macOS uses the processor. A GPU makes whisper models faster, and the released Linux and Windows builds pick it up without a setting

Where does my voice go?

Into the local recognizer, and then a JSON line in your journal. Nothing is uploaded by default. The network is used for the weight download and for a cloud language model provider that you configure yourself. The full list of addresses is in docs/outgoing-endpoints.md

Is the microphone always listening?

No. The stream opens on the key press and closes after the release, on a cancel and on an error. The delay between the release and the close is measured and written to the journal, so the claim is checkable

Which model is the default, and how do I change it?

GigaAM-v3 e2e RNNT at Q4_K_M, a Russian model from Sber, and the engine is auto, which follows the catalog entry of that model. molva models list shows the alternatives, molva models pull <name> downloads one, and molva config set stt.model <name> selects it. Restart the daemon to load different weights

Does it understand my language?

Russian is the default speech language and the fastest path: GigaAM understands Russian only. English dictation needs a manual switch to a multilingual whisper model: molva config set stt.engine whisper-cpp, molva config set stt.model small, molva config set stt.language auto. To go back: stt.engine auto and stt.model gigaam-v3-e2e-rnnt-q4_k_m. There is no automatic routing between models. The interface language follows the system (ui_language = "auto")

Does it work on GNOME or KDE?

Yes, in toggle mode. Those desktops do not report a key release to the application, so push-to-talk is impossible there. Hyprland and Sway report both events. On X11 without a desktop, the evdev backend reads the keys directly and needs membership in the input group

Are Windows and macOS as well tested as Linux?

No, and the repository says so. CI builds all three systems and releases carry an installer for Windows, a dmg for Apple silicon and a CLI archive for macOS. Some live checks, such as pasting in the Russian layout on Windows, are listed as not verified in docs/STATUS.md

Do I have to use Nix?

No. install.sh installs a built binary into ~/.local/bin without administrator rights, and it prints the dependency commands for your distribution instead of running them. Ready builds are on the releases page. Nix gives a dev shell, a package and a Home Manager module with the settings and weights taken from the store

What does the Nix-managed mode change?

The Home Manager module renders the settings file and the model weights into the Nix store. A switch is the only thing that changes them, and the GUI hides its settings page because the file is read-only. The daemon runs as a user service and the Hyprland binds are written from your configuration. Details in settings

Can I transcribe a video file?

Yes. molva transcribe film.mp4 --timecodes prints segments with their start and end, and --json gives a machine array. A directory, a nested tree and a stream on stdin work too. The result goes to the journal, so molva search finds it later

Can I edit text by voice instead of dictating new text?

Yes, that is command mode: select a paragraph, press Ctrl+Alt+X, say what to do, press again, and the selection is replaced in place. It needs a language model, local or cloud, and the model is enabled with llm.enabled = true

Is there telemetry or an account?

Neither. There is no sign-up, no analytics on this site and no telemetry in the application. The configuration carries a privacy.telemetry key that exists to be false and to state this explicitly

Is the project finished?

No. It started at the V0ICE hackathon in Kazan in September 2026 and is in development. The status page lists what works and what is cut, and it links the canonical file in the repository
