CLI guide

Canonical source: crates/molva/src/main.rs

Recipes for the tasks people actually run. Every option is listed once, on the CLI reference, so this page stays about intent

Dictate without a hotkey

The daemon must be running. The commands are the same ones a compositor bind calls, and they return before the phrase is finished

molva record start
molva record stop

A cancel throws the audio away and creates no journal line

molva record cancel

molva record toggle --mode command edits the selected text instead of dictating at the cursor

Put the last phrase into a field again

No second dictation and no clipboard trip by hand

molva history paste --last

An identifier from molva history works in place of --last, and its beginning is enough

Transcribe a folder of recordings

The input may be audio or video. One unreadable file does not cancel the batch; the exit code 6 reports that not everything went through. The command works without a daemon: it loads its own engine, which makes it the path for offline batches

molva transcribe talks/ --recursive --timecodes -o talks/transcripts/

For a pipeline, ask for JSON on stdout. The format hint helps with a stream that has no file name

cat recording.opus | molva transcribe - --stdin-format ogg --json

The result also enters the journal, which is what makes the search work later

Find something you recorded

molva search "release date" --since 7d

A hit prints the source file and the timecode of the segment that holds the match. --json gives the same as an array for a script, and an empty query lists the newest transcriptions

Read and export the history

molva history --limit 5 --format plain
molva history export history.csv

--app and the time window narrow the list, --search looks inside the text. A CSV export opens in a spreadsheet, and a JSONL export is the journal itself

Manage the weights

molva models list
molva models pull gigaam-v3-e2e-rnnt-q4_k_m
molva models verify gigaam-v3-e2e-rnnt-q4_k_m

The list marks what is already on disk. verify rechecks the checksum, path prints the file location, and remove deletes one file

Diagnose a quiet machine

molva doctor
molva status --json
molva test-inject

The doctor explains its findings line by line. status --watch follows the daemon events when a phrase seems to vanish

Change a setting

molva config set output.mode clipboard
molva config reload

Profile export and import move a working setup to another machine. The model, the engine and the paste chain need a daemon restart, because they are built at start

Script against it

Use the exit code, not the text. A bind shows nothing to the user, but a script sees the number

Exit codes, repeated here because scripts depend on them
CodeMeaning
0Everything worked
2Wrong arguments or an unknown name
3The daemon is not running or does not answer
4The daemon is busy with the previous phrase
5Error of the recognition engine
6Could not read or write a file
7The daemon is already running

The machine-readable flags are --json on history, status, stats, models list, transcribe and search. Completion scripts come from molva completions bash and its siblings
