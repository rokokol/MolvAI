Privacy and the journal

Canonical source: docs/journal-schema.md and docs/outgoing-endpoints.md

The microphone

The capture stream opens at the key press and closes right after the release. The close does not depend on how the phrase ended: a cancel, an error and an abnormal exit of the daemon all release the device

The delay from the release to the close is measured, logged and written to the journal as latency_ms.stop_after_release. That is why the claim is checkable rather than a promise

The journal

The only storage of dictation data is one JSONL file, journal.jsonl, under $XDG_DATA_HOME/molva/ and the matching platform directories. It has permissions for the owner only, one phrase per line, and it is append-only. Deleting an entry, cleanup and rotation rewrite the file atomically

What a line holds, in groups
GroupFields
Identityschema, id, ts, session_id, mode, source
The phraseapp, language, audio_secs, words, wpm, style, stt_engine, stt_model
Post-processingllm_provider, llm_model, llm_used, local_llm, dict_hits, tokens
Deliveryinject_method, latency_ms, error
Texttext_raw, text_final, audio_path, all optional and absent in privacy mode

The latency object carries stt, rules, llm, inject, total, first_hypothesis and stop_after_release. Every field and every calculation rule is in docs/journal-schema.md

The switches

What to set, and what each setting removes
SettingEffect
journal.include_text = falseThe line is written without the phrase texts and the audio path. Every metric stays
journal.encrypt = trueThe texts are sealed with XChaCha20-Poly1305. The other fields stay open, so statistics and filters work without the key
journal.key_sourcefile means journal.key next to the journal, created with owner permissions; keyring means the entry journal-key in the OS store
journal.enabled = falseNo journal line is written
privacy.no_record_mode = trueNo journal and no history at all
journal.max_entriesHow many phrases the journal keeps; the oldest go first
privacy.send_to_llm = falseNo text is sent to the configured language model
privacy.telemetryThere is no telemetry; the key exists to be false

Without the journal key, the tools show empty text fields instead of ciphertext. The key is created by itself at the first opening of an encrypted journal

What leaves the machine

The network has few uses, and each waits for an explicit command or an explicit configuration

  • molva models pull, or the automatic download at daemon start, fetches the weights from the catalog address and checks the SHA-256. A mirror serves the same files from a directory you name
  • A language model provider that you configure receives the text of a phrase when llm.enabled and the style ask for it. Ollama on localhost is the default provider, so the default path stays on the machine

The complete list of addresses the program can call is in docs/outgoing-endpoints.md. The tests do not use the network

Command mode and the clipboard

Command mode needs the selected text. The daemon copies the selection with a Ctrl+C combination through the compositor. It clears the clipboard before the copy, so a stale selection cannot be read, and polls for the result for up to 600 ms. The model receives the selection and the instruction

Normal dictation does not touch the selection. With output.restore_clipboard = true, which is the default, a paste returns the previous clipboard content afterwards

Delete what you recorded

molva history clear --yes
./install.sh --uninstall --purge

The first clears the phrases and keeps the settings. The second removes the installation together with the history; without --purge the installer asks about the journal
