Models

One catalog, two recognizers

A model is a weights file and a name in models.toml. The CLI, the GUI and the Nix module read that one file, so a name means the same thing everywhere

Default

GigaAM-v3 e2e RNNT Q4_K_M

Russian speech, recognized locally on the CPU. 175 MiB, engine transcribe-cpp, quantization Q4_K_M, license and terms in the model license document

ru 175 MiB Q4_K_M transcribe-cpp Sber GigaAM-v3

molva models pull gigaam-v3-e2e-rnnt-q4_k_m

Why this model is the default

Russian dictation is the main case, and the CPU is the hardware everyone has. GigaAM is a Russian-first family, and the Q4_K_M file keeps the model at 175 MiB, so it starts quickly and fits beside other work

The engine is auto: it follows the catalog entry, so you never have to know that a GigaAM file is not a whisper file. The transcribe.cpp runtime is the one that loads this format

A Ryzen 7 4750U ran 10.98 s of audio in 630 ms in transcribe.cpp's published benchmark, about 17× realtime. That is an upstream figure, not this project's

The catalog

Sizes are the file sizes from models.toml, in binary units. The SHA-256 of each file is checked before it reaches the disk

Model weights known to models.toml, in catalog order
Model Language Engine Quantization Size Notes
gigaam-v3-e2e-rnnt-q4_k_m ru transcribe-cpp Q4_K_M 175 MiB Default. Russian-first, CPU friendly
tiny multilingual whisper-cpp not stated 74 MiB The smallest whisper file. Fast and rough
base multilingual whisper-cpp not stated 141 MiB Faster than small, clearly worse
small multilingual whisper-cpp not stated 465 MiB The previous default and the compromise point of whisper.cpp
small-q5_1 multilingual whisper-cpp Q5_1 181 MiB small at a quarter of the size, a little accuracy lost
medium multilingual whisper-cpp not stated 1.43 GiB More accurate than small, much heavier
large-v3-turbo multilingual whisper-cpp not stated 1.51 GiB Accurate and practical on a GPU
large-v3-turbo-q5_0 multilingual whisper-cpp Q5_0 547 MiB The turbo model squeezed into a third of the space
large-v3-turbo-q8_0 multilingual whisper-cpp Q8_0 834 MiB Turbo with little quantization loss
large-v3 multilingual whisper-cpp not stated 2.88 GiB The largest file in the catalog. Memory and time to match

"Not stated" means the catalog does not declare a quantization for that file; the name states it whenever the catalog carries a quantized variant. The languages of the whisper rows are described as multilingual by whisper.cpp, while stt.language and allowed_languages decide what MolvAI may choose

Switch a model

One setting, or one flag for a single file. The daemon loads the recognizer when it starts, so a new dictation model takes effect after a restart

For dictation

molva models pull large-v3-turbo
molva config set stt.model large-v3-turbo

The engine stays auto and follows the catalog entry of the new model. The recognizer is built at daemon start, so restart the daemon to load different weights

For one file

molva transcribe talk.m4a --model large-v3-turbo

The override applies to that run. Your own weights fit too: point stt.model_path at the directory and name the file in stt.model

Where the weights come from

Hugging Face by default, with a SHA-256 check from the catalog. stt.models_mirror points at a directory that serves the same file names. The checksum check still runs, so a plain http:// mirror on a local network is fine

Licenses of the weights

The repository is MIT. The weights are not covered by that license and carry their own terms, collected in docs/model-licenses.md. Read it before you redistribute a model

With Nix, the weights come from the store

The Home Manager module fetches the selected models at evaluation time and renders stt.model_path into the store. A switch is the only thing that changes a model, and the GUI hides its settings page because the file is read-only. Details in settings and the Nix-managed mode
