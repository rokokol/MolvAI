Just local.

Why it is built this way

Promises the code keeps

The interesting part of a dictation tool is not the transcription. It is what happens to your voice when you stop talking

01

The microphone is open only while you talk

The capture stream opens on the key press and closes right after the release, including on a cancel or an error. The measured delay from release to close is written to the journal as latency_ms.stop_after_release, so you can check the promise instead of trusting it

02

Russian by default, English with a manual switch

The default model is GigaAM-v3 e2e RNNT at Q4_K_M, 175 MiB, and the default engine is auto. It recognizes Russian speech on the CPU without a video card. English dictation needs a manual switch to a multilingual whisper model: stt.engine = "whisper-cpp", stt.model = "small", stt.language = "auto"

03

Every phrase stays findable

A JSONL journal holds the text, the timing, the app and the model of each phrase. molva history, molva stats and molva search read that one file, and a file transcription keeps its timecodes

The 20-second version

Install, hold a key, speak, release

No account to create, no model to choose before the first phrase. The daemon fetches the default weights at start and checks their SHA-256

  1. Install with Nix, or with the script

    With Nix nothing enters the system. Without Nix, install.sh checks the dependencies and installs nothing itself

    nix run github:rokokol/MolvAI -- --help

  2. Start the daemon

    It opens the socket, loads the default GigaAM model and listens for the hotkeys. The Home Manager module runs the same command as a user service

    molva daemon

  3. Hold F9 and speak

    Chunks are recognized while you speak, so the draft is ready when you stop, and the field receives the text as one piece after the release. A short tap latches the recording hands-free

  4. Release, and the text is in the field

    The paste method is chosen automatically and the phrase goes to the journal. molva history --last brings it back without dictating it again

    molva history paste --last

Privacy

The network is used twice, and both times you ask

Capture, recognition, the dictionary, the rules, the paste, the journal, the statistics and the GUI all work with the cable pulled out

Microphone

The stream exists for the length of one recording. Outside a recording MolvAI listens to nothing, and the system recording indicator is off

Journal

One JSON line per phrase, file permissions for the owner only. journal.include_text = false drops the text, privacy.no_record_mode = true stops the journal, and journal.encrypt seals the texts with XChaCha20-Poly1305

Network

Only molva models pull downloads weights, and only a cloud language model provider that you configure calls out. privacy.telemetry exists to be false

Install

Pick the way that fits your machine

With Nix the toolchain stays in the store. Without Nix, the installer prints the exact commands for your distribution and changes nothing without you

Build and run without cloning

nix run github:rokokol/MolvAI -- --help

With Home Manager, the flake module installs molva, runs the daemon as a user service and writes the Hyprland binds from your settings

# flake inputs: molvai.url = "github:rokokol/MolvAI";
imports = [ inputs.molvai.homeModules.default ];
programs.molvai.enable = true;

Clone, check, install

git clone https://github.com/rokokol/MolvAI && cd MolvAI && ./install.sh

The binary goes to ~/.local/bin and needs no administrator rights. ./install.sh --check prints the dependency commands for Debian, Fedora, Arch, openSUSE, macOS and Windows, and the script installs none of them itself

./install.sh --uninstall

Removal follows the manifest, so it takes exactly what was installed

Download a build

The releases page carries the CLI archives for Linux, Windows and macOS, an AppImage, deb, dmg and a Windows installer. Each file has a SHA-256 sum in sha256sums.txt. The Linux and Windows builds use Vulkan for whisper models and fall back to the CPU when no Vulkan device exists. Separate CUDA archives for Linux and Windows carry the NVIDIA runtime
