Features

Dictation first, and the small things around it

MolvAI is one pipeline with one storage file. Each feature below is a setting of that pipeline, not a separate service. Where a feature has a limit, the limit is named too

Dictation

From a held key to a finished sentence

Any application

The text goes into the field that has the focus: an editor, a chat, a terminal, a browser form. The paste method is chosen automatically and the journal records which one worked. In a terminal the shortcut switches to Ctrl+Shift+V

Hold, tap or cancel

Hold F9 to dictate while the key is down. A short tap latches the recording, and the next tap ends it. Ctrl+Alt+Z toggles from anywhere, Ctrl+Alt+C throws the recording away. Every combination is a setting

Text while you speak

With stt.chunked the phrase is cut at short pauses and each chunk goes to the model during the recording. With stt.streaming_inject the finished chunks are typed as they arrive, so a long paragraph is mostly on screen before you release the key

Two recordings never collide

The next phrase records while the previous one is recognized. The daemon counts the phrases in processing and goes back to ready after the last one. Exit code 4 appears only when the previous phrase truly blocks the request

Text quality

Cleanup without a model, a model when you want one

The default pipeline is deterministic: a term dictionary and a rule set. No token leaves the machine unless you turn the model on

Dictionary and rules

Your names and product terms are substituted fuzzily. Spoken punctuation becomes punctuation, filler words disappear, repeats collapse, numerals become digits. The rules run in milliseconds and are covered by the same tests as the rest

Styles per application

Verbatim, Cleanup, Messenger, Email, Code and Formal. One is the default, and style.by_app gives a window class its own style: terse in a messenger, formal in mail

Optional language model

Off by default. When on, it speaks the OpenAI-compatible protocol and Ollama is the default provider. It runs only for phrases longer than rules.llm_min_words and only for styles that need it. A timeout returns the text after the rules, never an empty field

Command mode

Select a paragraph, press Ctrl+Alt+X, say "make it shorter" or "translate to English", press again. The selection is replaced in place. This is the project's original feature, and it needs a model

Files and search

Your recordings become text you can search

Audio and video, with timecodes

A single path, a directory, a nested tree or a stream on stdin. molva transcribe --timecodes prints segments with their start and end, --json gives a machine array, and one bad file does not cancel the batch

molva transcribe talks/ --recursive --timecodes

Search across transcripts

Every transcription lands in the same journal. molva search finds a phrase in any of them and prints the source file with a MM:SS.mmm timecode. There is no second index to fall out of date

molva search "release date" --since 7d

Journal and statistics

One JSON line per phrase: text, words, words per minute, style, engine, model, dictionary hits, the paste method and the latency of every stage. molva stats turns it into averages, a personal record and a daily picture

History that comes back

molva history paste --last puts the previous phrase into the field again without a second dictation. Filters by app and time, export to JSONL or CSV, delete one line or clear all of it

Privacy and portability

Local by construction, not by a setting

Microphone discipline

The device opens on the press and closes on the release. The close does not depend on how the phrase ended, and its delay is measured and journaled

Encryption and no-record mode

The journal texts can be sealed with XChaCha20-Poly1305 and a key in the OS store or a 0600 file. The statistics keep working without the key. No-record mode writes nothing at all

Offline

Only the weight download and a cloud model provider use the network, and both wait for your command or your configuration. Everything else works with the cable out

Nix first

The flake gives a dev shell, a package and a Home Manager module. The module renders the settings file and the weights into the store, runs the daemon as a user service and writes the Hyprland binds

Other systems

Ready builds exist for Linux, Windows and macOS, and the installer checks dependencies instead of installing them. The paste chain falls back to the clipboard when the compositor refuses

Model choice

GigaAM-v3 by default, whisper.cpp models when you want them. Downloads are checked against a SHA-256 from the catalog, and stt.models_mirror serves the same file from a local network

Limits

What it does not do yet

The project is in development. A feature list without a cut list is marketing, so the cut list lives in the open

Read the status page before you rely on a feature

Known gaps include the Windows and macOS checks on live hardware, which the status log lists as unverified. The releases carry CUDA builds for Windows only. The canonical list is docs/STATUS.md, summarized on the status page

Speech in the middle of a phrase

A whole English sentence inside a Russian phrase is not read as English. Latin insertions and terms work, and the language is chosen once per phrase

Pre-roll audio

The first syllable you say before the microphone opens is lost. A pre-roll needs a permanently open stream, and this project keeps the microphone closed
